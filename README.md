# zbalerlatmo

Fonts that render ordinary Latin-orthography Lojban as
[Zbalermorna](https://jackhumbert.github.io/zbalermorna/write-up), entirely
through OpenType shaping. The text itself stays plain Lojban: searchable,
copyable and editable without an input method. Switching a page between Latin
and Zbalermorna is just a change of `font-family`.

The fonts are built from the upstream Zbalermorna fonts in
[`zbalermorna/`](zbalermorna) (imported from
[jackhumbert/zbalermorna](https://github.com/jackhumbert/zbalermorna) with its
history). The upstream Private Use Area encoding (U+ED80–U+EDBF) keeps working
as before, so the fonts also serve IME users.

| Font | Built from | Latin companion |
| --- | --- | --- |
| Crisa Latmo Regular | `crisa-regular.otf` | Lato Regular |
| Crisa Latmo Light | `crisa-light.otf` | Lato Light |

Built fonts are in [`fonts/`](fonts), as OTF and WOFF2.

## Using the fonts on a web page

```css
@font-face {
  font-family: "Crisa Latmo";
  src: url("CrisaLatmo-Regular.woff2") format("woff2");
}

.zbalermorna {
  font-family: "Crisa Latmo", serif;
}
```

Apply the font only to Lojban. Text in other languages inside a Lojban
element, such as the contents of `zoi gy. … .gy.` or `la'o gy. … .gy.`, or
tooltips, should be wrapped in an element that keeps the Latin font:

```html
<p class="lojban">.i se finti la'o gy. <span class="glico">Burt Bacharach</span> .gy.</p>
```

```css
.zbalermorna .glico { font-family: serif; }
```

## What the fonts understand

The input is well-formed Latin Lojban. In particular:

- **Names (cmevla)** must be followed by a period, as in `la .djan.`. A name
  is recognised by its final consonant before that period; its vowels are
  written as full vowels. Other words, including fu'ivla, use vowel
  diacritics.
- **Vowel-initial words** should start with a period (`.i`, `.ui`). A bare
  vowel still gets the period radical.
- **Glides**: `i` and `u` before a vowel become the glide radicals, which take
  precedence over diphthongs (`.maias.` is ma-ias). The four diphthongs `ai`,
  `ei`, `oi`, `au` become single diphthong diacritics, or single full-vowel
  letters in names.
- **Apostrophe**: `'`, `’` (U+2019) or `h`. Between vowels `'` and `’` are the
  apostrophe; anywhere else they are quotation marks.
- **Comma**: between two letters it separates syllables (`.i,an.` vs
  `.ian.`); anywhere else it is a visible comma.
- **Stress**: a capital vowel (`klAma`), or an acute or grave accent
  (`kláma`, precomposed or combining). It is drawn as the stress dot. A
  stressed diphthong takes one dot.
- **Stretch**: a tilde after a vowel (`gle~ki~~`) draws the stretch mark.
- **Attitudinal shorthand**: `.V'V` (for example `.e'u`) is drawn with the
  combined period-and-apostrophe form, as the upstream fonts do.
- Punctuation and digits render as Latin; quotation marks, dashes, the
  ellipsis and digits are taken from the Latin companion font.

All of this lives in `rlig`, the one ligature feature that applications and
CSS (`font-variant-ligatures: none`) cannot turn off. Where no shaping happens
at all, the text shows as Latin Lojban.

## Building

```bash
pip install -r requirements.txt
python -m latmo.build            # all fonts in fonts.toml
python -m latmo.build crisa-regular
```

`fonts.toml` lists the fonts to build. The lookups are generated by
[`latmo/features.py`](latmo/features.py); [`latmo/build.py`](latmo/build.py)
adds the glyphs and cmap entries and merges the generated lookups ahead of the
upstream font's own lookups.

To see what a string shapes to:

```bash
python -m latmo.shape fonts/CrisaLatmo-Regular.otf ".i mi klama la .djan."
```

## Tests

```bash
python -m pytest tests
```

`tests/cases/manual.tsv` holds hand-checked cases. `tests/cases/corpus.tsv`
holds dictionary words and sentences whose expected output was produced by an
independent Latin-to-Zbalermorna renderer and shaped with the original
upstream font; the same text in the PUA encoding must shape identically, which
checks that upstream behaviour is preserved.
