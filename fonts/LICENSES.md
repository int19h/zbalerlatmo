# Font licenses

Every font here is a modified version of an upstream Zbalermorna font from
[jackhumbert/zbalermorna](https://github.com/jackhumbert/zbalermorna) (in
`zbalermorna/` in this repository). The Zbalermorna glyphs were drawn by Jack
Humbert and contributors. This project adds Latin input glyphs, Latin
punctuation and OpenType lookups. Each font keeps the license of the font its
upstream design was derived from. The license texts are in
[`licenses/`](licenses).
